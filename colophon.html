This website is made with lwk, my Lua static site generator. The code for the site can be found in this repository. It is also is designed to be fully functional without JavaScript; the only usage of JavaScript on this site is for Plausible Analytics, which is completely anonymous (no user identifiers, no cookies) and not strictly required for anything to work properly.

The light mode colorscheme used on this website is my own colorscheme, elysium, and the dark mode colorscheme is Everforest by sainnhe ("Hard Dark" variant, prior to c7d3ffe).
