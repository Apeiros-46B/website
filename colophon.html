colophon

This website is made with lwk, my Lua static site generator. The code for the site can be found in this repository. It is also is designed to be fully functional without JavaScript; the only usage of JavaScript on this site is for Plausible Analytics, which is completely anonymous (no user identifiers, no cookies) and not strictly required for anything to work properly.

theme#

The light mode color palette used on this website is my own theme, elysium, and the dark mode color palette is Everforest by sainnhe ("Hard Dark" variant, prior to c7d3ffe). The background artwork was made and matched to the palettes using Blender, Affinity, and lutgen.

generative AI usage#

The content on this website is entirely human-written. LLM-based tools are lightly used for some of my software projects, but I do not use GenAI to assist in the creation of images, videos, or music.
