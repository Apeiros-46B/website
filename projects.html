qalc.nvim#

February 2026–November 2026 (rewrite, old version from 2022)

  • C++
  • Lua
  • Neovim
  • libqalculate

qalc.nvim is a text-based reactive math worksheet inside of Neovim. It allows you to write expressions that depend on others, edit their values, and watch the results update in real time. With libqalculate as a backend, advanced features like unit conversion, algebra, and calculus are available and integrated with diagnostics, syntax highlighting, and autocompletion support.

lwk#

February 2026–March 2026

  • Lua
  • HTML
  • CSS

lwk (Lua Website Kit) is a web templating engine/SSG in ~1300 SLOC. It's mostly a bespoke tool made for this website because I got tired of hand-writing HTML and CSS but didn't want to use a complex JS framework. It allows pages, templates, and reusable components to be written using a Lua-based DSL, which are compiled into raw HTML + CSS.

sidechain#

January 2026

  • Rust

sidechain is a bulk audio transcoder for creating Opus libraries. None of the existing software I found for mirroring lossless music libraries to lossy formats suited my use case, so I made this. Designed to be run in a cron job, it uses SQLite to track files and opusenc to transcode lossless ones, avoiding wasted work on unchanged input files and passing through lossy and non-audio files (such as cover images). I plan to generalize this into a one-to-one rule-based "file mapper" in the near future.

raytracer#

May 2024–June 2024

  • Rust
  • GLSL
  • OpenGL ES
  • egui

raytracer is a path-tracing renderer that supports simple objects (ellipsoids and boxes). It implements path tracing to approximate realistic lighting, running in a fragment shader in OpenGL for GPU acceleration. It's written in Rust using egui for UI interaction and can run either in the browser (via WebAssembly and WebGL) or as a native application. It doesn't have any acceleration structures or other optimizations; I just built it to learn basic graphics programming concepts at the time.
